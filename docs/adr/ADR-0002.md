# ADR-0002 — Separação por camadas fora de `app/`

**Status:** Aceito
**Data:** 2026-08-31

## Contexto

O App Router transforma toda pasta dentro de `app/` em segmento de rota, a menos
que ela seja privada (`_pasta`). Um projeto de avaliação precisa que a leitura do
repositório mostre a arquitetura sem esforço, e que a fronteira com o back-end
(inexistente, mockado) fique óbvia.

A documentação do Next.js descreve duas estratégias válidas: colocar arquivos de
projeto dentro de `app/` (colocation), ou mantê-los fora
(`node_modules/next/dist/docs/01-app/01-getting-started/02-project-structure.md`,
seção "Store project files outside of `app`").

## Decisão

Camadas como pastas de primeiro nível, irmãs de `app/`:

```
app/         rotas — só composição
components/  UI pura — props entram, JSX sai
features/    lógica de domínio, uma pasta por tela
lib/         contratos, tipos, cliente de API
mocks/       dados falsos, latência e erro simulados
docs/adr/    decisões de arquitetura
```

A dependência corre numa direção só:

```
app/  →  features/  →  lib/  +  components/
                          ↑
                      mocks/ implementa o contrato de lib/
```

Cada pasta carrega um `README.md` declarando o que ela pode e o que ela não pode
importar. O alias `@/*` já existente em `tsconfig.json` resolve para a raiz, então
`@/features/envio` e `@/lib/api` funcionam sem configuração adicional.

## Por quê

- **`components/` não conhece domínio.** O teste é renderizar isolado, só com
  props, sem nenhum mock. Isso é o que permite trocar o mock por HTTP real sem
  tocar em componente.
- **`lib/` é a única camada que sabe como uma requisição é feita.** `features/`
  importa funções tipadas e nunca descobre se por trás existe mock ou API. Essa
  é a decisão que faz o mock ser descartável em vez de estrutural.
- **Uma pasta por tela em `features/`** mantém o escopo das 3 telas visível na
  árvore de arquivos. Uma quarta pasta aparecendo ali é sinal de escopo
  crescendo sem confirmação.

## Alternativas descartadas

- **Tudo dentro de `app/`, com pastas privadas (`_components`).** Funciona, mas
  esconde a arquitetura dentro da árvore de rotas e mistura duas hierarquias
  (rota e camada) na mesma pasta.
- **`src/`.** O Next suporta. Adiciona um nível de indentação sem separar nada
  que as camadas já não separem.
- **Agrupar por tipo de arquivo** (`hooks/`, `utils/`, `types/`). Descartado:
  espalha uma mesma tela por cinco pastas e não cria nenhuma fronteira real.

## Custo de reverter

Baixo. Mover pastas e ajustar imports — o alias `@/*` absorve a maior parte.
